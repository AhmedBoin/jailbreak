# Domains

Each folder under `domains/` is a software category. A project is a folder one level deeper:

```text
domains/<domain>/<project>/
```

Use a domain when the category is clear. Create a new domain when a project does not fit an existing one.

Current domain names and scopes are listed in the root [`README.md`](../README.md). Projects are not listed there by design. Browse this folder to discover them.
